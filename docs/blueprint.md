# **App Name**: SpeakSmart AI

## Core Features:

- Voice Conversation Engine: Enable real-time voice conversations between the user and the AI, with the AI responding naturally.
- Speaking Modes: Offer free conversation, guided practice, and roleplay modes to cater to different learning preferences.
- Real-Time Feedback: Provide short, direct corrections after the user finishes speaking, focusing on grammar, pronunciation, vocabulary, and fluency.
- Speaking Score: Tool that analyzes the sessions and gives scores after each session for fluency, pronunciation, grammar, and confidence, displayed with historical comparison.
- Session Recording & Playback: Allow users to save and replay audio sessions to compare their progress over time.

## Style Guidelines:

- Primary color: Soft blue (#79BAEC) to inspire calm and confidence.
- Background color: Light blue (#E0F2F7) creates a clean and calming conversational environment.
- Accent color: Lavender (#B689C0) for feedback and highlights, analogous to blue yet distinct.
- Body and headline font: 'Inter', a grotesque-style sans-serif for a modern, machined, objective, neutral look, suitable for headlines or body text.
- Use minimalist icons for controls (microphone, playback) that are clear and unobtrusive.
- A clean and distraction-free layout focused on the speaking interface.
- Subtle animations for loading states and feedback display to provide a smooth user experience.
